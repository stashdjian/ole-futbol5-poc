# Ole - Fútbol 5 POC

Prototipo de fútbol por turnos con IA declarativa.

## Cómo usar

1. Abrí `index.html` en el navegador, o activá GitHub Pages.
2. Planificá el Equipo A (azul).
3. Apretá **Plan IA (Equipo B)** para que la IA genere el plan del equipo rojo.
4. Ejecutá el turno.

La lógica de la IA está en `ai_logic.json` y embebida en el HTML.
